# Support

For questions about a specific implementation, first review that repository’s README, documentation, and open issues. Use its issue tracker for reproducible bugs and public documentation questions; avoid posting private data, credentials, or security-sensitive details.

For feature proposals, use the Feature Request issue template and describe the use case, constraints, and alternatives considered. For security concerns, follow [SECURITY.md](SECURITY.md) and never post exploit details publicly.

For general project information, visit the [official website](https://orakzaibond.com). No service-level agreement or guaranteed response time is provided through GitHub. These repositories are informational and do not provide investment, legal, tax, or financial advice.
